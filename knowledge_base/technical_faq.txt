# Technical Support and System FAQ

## Supported File Formats and Upload Limits
SupportFlow AI supports attaching documents and data files directly to support tickets:
- Supported Extensions: PDF (.pdf), CSV (.csv), Excel (.xlsx), PNG (.png), JPEG (.jpg, .jpeg), and plain text (.txt).
- Maximum File Size: 25 megabytes (MB) per single file attachment.
- Executable files (.exe, .dmg, .bat, .sh) and archive files (.zip, .tar) are strictly blocked for security reasons.

## Supported Web Browsers
For optimal security and performance, we officially support the following browser versions with JavaScript enabled:
- Google Chrome: Version 110 or higher.
- Mozilla Firefox: Version 115 (ESR or Standard) or higher.
- Apple Safari: Version 16.0 or higher (macOS and iOS).
- Microsoft Edge: Version 110 or higher.
Legacy browsers, including Microsoft Internet Explorer, are not supported.

## API Limits and Rate Throttling
All API integrations must adhere to tiered rate limits based on active subscription:
- Starter & Professional Plans: 10,000 API requests per rolling 60-minute window.
- Enterprise Plan: 100,000 API requests per rolling 60-minute window.
If rate limits are exceeded, the API returns an HTTP 429 Too Many Requests status code with a 'Retry-After' header.

## Troubleshooting 500 Internal Server Errors and Outages
If you encounter an unexpected HTTP 500 Internal Server Error:
1. Clear your browser cache and cookies, then try refreshing the web page.
2. Check if the issue persists in a private/incognito browser window.
3. If the error continues, capture the exact timestamp, current URL, and error message and submit a ticket to Technical Support for log inspection.
